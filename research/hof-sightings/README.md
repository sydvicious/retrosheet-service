# HOF sightings

**Question:** which Hall of Famers have I seen, and when did I first see each one?

Cross-references Syd's personal **attended-games log** against the Retrosheet
mart: for every game he was at, who took the field, and which of them are in the
Hall of Fame. Produces a printable Cooperstown plaque checklist and flags any
box-score links in the log that don't resolve.

## Input

`attended-games.tsv` — one game per line, `date <TAB> Retrosheet box-score URL`:

```
7/22/1988	https://www.retrosheet.org/boxesetc/1988/B07220HOU1988.htm
```

Derived from Syd's master attended-games spreadsheet (the study only needs the
date and the box-score link — the `game_id` is parsed out of the `B…` box code).
**Updated ~yearly:** add the new games' rows, re-run, get a refreshed checklist.

## Run

Research default is Plex (production); override with `DATABASE_URL`:

```bash
tsx research/hof-sightings/run.ts
DATABASE_URL=postgres://retrosheet:retrosheet@localhost:5432/retrosheet tsx research/hof-sightings/run.ts
```

## Generated vs hand-written

Generated by `run.ts` (don't hand-edit):
- `01-hall-of-famers.md` — the players checklist (induction order), plus a second
  table of HOF people seen managing.
- `bad-links.md` — links that don't resolve to a game on the logged date, with the fix.
- `hall-of-famers.html` — the printable plaque checklist, both tables (open, ⌘-P).

`FINDINGS.md` is interpretation and is never regenerated.

## Scope & method

- **Players only.** A Hall of Famer counts if Syd saw them *take the field* — a
  start or substitution in `lineup_start` / `substitution`, joined to
  `people.hof = 'HOF'`. Only **inducted** members appear (they're the ones with
  plaques). Managers are deliberately excluded — see below.
- **First sighting** = earliest correctly-linked attended game in which the player
  appears. Games whose link is wrong (see `bad-links.md`) are excluded so a
  mis-linked game can't fabricate a date.
- **Induction order.** The list is sorted by Hall of Fame induction year, the way
  the Cooperstown Plaque Gallery is arranged (chronological by class), tiebroken
  alphabetically. The year isn't in Retrosheet's data (the `hof` field is a bare
  flag), so it's fetched once per player from their Retrosheet bio page and cached
  in `hof-induction.ts`. Regenerate that cache when new HOF players are added.
- Non-Retrosheet rows (baseball-reference, minor-league, college, NPB) are
  skipped — not in the MLB mart.

## Managers table

Seeing a Hall of Famer *manage* is a different thing from the plaque you check off,
so managers are kept out of the **main** checklist — but they get their own table
at the bottom: every HOF person seen as manager of record, **any** induction
category, so the categories can be judged by eye. That's necessary because the data
can't judge them: Retrosheet's `hof` flag has **no induction category**, and it
can't be inferred — 130 HOF people have a `mgr_debut` (player-managers, plus modern
coaches with a one-game acting-manager stint), but only ~22 were enshrined *as*
managers.

Supporting pieces: the manager-of-record data is in the mart's **`game_log`** table
(`visitor_manager_id` / `home_manager_id`, loaded by the ETL from Retrosheet's game
logs), and **`hof-managers.ts`** holds the curated list of manager-inductees that a
future "HOF *managers* I saw" query (filtering out the player-inductees) would join
against.
